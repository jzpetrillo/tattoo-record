- If user.avatarUrl exists → show the image (object-cover, sharp corners to match Press).
- Else → render a deterministic initials block: user's initials (from firstName/lastName, else username[0]) on a cobalt background with paper text, Space Grotesk. Replace all existing ad-hoc avatar/AvatarFallback usages with this component.

- server/services/cloudinary.ts: export isCloudinaryConfigured() (true only if all three CLOUDINARY_* envs are present). In the /api/upload route (server/routes.ts ~1424), if not configured return 503 {"message":"Image uploads are temporarily unavailable."} instead of a 500.
- client: in create-post-modal.tsx, settings.tsx (avatar/banner upload), and anywhere uploadFile() is used, surface the server message as an error toast, and re-enable the form (don't leave it stuck in "Sharing…"). If uploads are unavailable, disable the file picker with a short note rather than letting the user pick a file that will fail.
- Add avatar + banner upload to settings.tsx Edit Profile if not already wired (uses the same uploadFile → PUT /api/users/me { avatarUrl }/{ bannerImageUrl }). NOTE: the update path must map to the real column bannerImageUrl (not bannerUrl).
