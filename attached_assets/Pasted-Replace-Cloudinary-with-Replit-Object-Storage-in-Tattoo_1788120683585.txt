Export, keeping the SAME shapes the routes already consume:
- `isStorageConfigured(): boolean` — true if a bucket is available (e.g. the Replit object-storage env/bucket id is present, or a lightweight client init check). Used for the 503 guard.
- `uploadMedia(file: Buffer, folder: string, userId: string, mimetype: string): Promise<UploadResult>`:
    - Build a namespaced key: `${folder}/${userId}/${crypto.randomUUID()}.${extFromMime(mimetype)}` (folder ∈ posts|stories|portfolios|avatars|banners|messages|general).     - `await client.uploadFromBytes(key, file)`; if not ok, throw.
    - Return `{ publicId: key, url: `/api/media/${key}`, type: mimetype.startsWith("video") ? "video" : "image" }` (lowercase type, matching prior Cloudinary output; width/height/duration are optional and omitted).
- `deleteMedia(key: string): Promise<void>` — `await client.delete(key)`.
- `getMediaStream(key)` / `downloadMedia(key)` — return the object's bytes or a readable stream (use `downloadAsStream` for video/range support) for the serving route.
- small `extFromMime()` + `contentTypeFromKey()` helper (map jpg/png/webp/gif/mp4/webm/mov). You may use a `mime-types` dep or a small inline map.
