---
name: Feature activation scope
description: Product intent for complete, visible features and the limits of deployment authorization
---

The user wants the app stable and features working, active, and neither hidden nor abandoned. A visible feature must have its existing server capabilities connected to the appropriate user flow, not only a browse-only screen.

**Why:** The user explicitly repeated this product goal while requesting completion of previously disconnected functionality.

**How to apply:** Audit the actual interaction and submitted payload, not just whether a navigation item is visible. This product goal is not permission to publish or access databases; honor each request's explicit limits on those operations.
